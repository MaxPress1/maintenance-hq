# Архітектура Maintenance HQ

## 1. Загальна концепція та технологічний стек
- **Frontend / Full-stack framework:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS.
- **Backend & Data layer:** PostgreSQL з розширеннями `uuid-ossp`, Row-Level Security (RLS) та збереженими функціями.
- **Автентифікація:** Supabase Auth (Email OTP / TokenHash / PKCE), без відкритої публічної реєстрації.
- **Файлове сховище:** Приватні Supabase Storage buckets із доступом через короткоживучі signed URLs.
- **Валідація та безпека:** Серверна валідація Zod, захист від CSV/Formula Injection, захист від циклічних залежностей та ієрархій, атомарні транзакції PostgreSQL.

## 3. Модулі системи

1. **Облік об'єктів (`src/features/assets/`):**
   Ієрархічна структура: Територія → Будівля / Зона → Поверх → Приміщення → Обладнання.
   Картки технічного стану, дати оглядів, архівація, захист від циклів.

2. **Заявки та ремонти (`src/features/work-orders/`):**
   Єдиний реєстр для планових, термінових та публічних заявок. 10 статусів життєвого циклу, матриця переходів, призначення відповідального, фотофіксація (до/під час/після), коментарі.
   Публічний прийом за захищеним токеном (`/report/[token]`).

3. **Планування та графік (`src/features/planning/`):**
   Канбан-дошка, календар та табличний реєстр на спільних фільтрах URL. Залежності робіт із запобіганням циклам, перенесення термінів із фіксацією причини.

4. **Матеріали (`src/features/materials/`):**
   Довідник матеріалів, фіксація потреб під роботу, списання використання, аудовані коригування залишків без створення прямих фінансових витрат.

5. **Бюджет та фінанси (`src/features/finance/`):**
   Річні бюджети, погоджені асигнування, журнал операцій, підтримка мультивалютних чеків із фіксованим ручним курсом UAH, механізм сторно, попередження про перевищення ліміту.

6. **Звіти та експорт (`src/features/reports/`):**
   6 типів аналітичних звітів, фільтрація, захищений експорт у CSV з кодуванням UTF-8 BOM та екрануванням формул.
