# Maintenance HQ

Адаптивний україномовний вебдодаток (PWA) для операційного управління об'єктами території, аварійними заявками, плановими ремонтами, матеріалами та бюджетом.

---

## Основні можливості

- **Рольовий доступ:** 4 ролі з можливістю суміщення (`administrator`, `coordinator`, `worker`, `finance`), захищені серверними перевірками та PostgreSQL RLS.
- **Облік об'єктів:** Ієрархічне дерево (Територія → Будівля / Зона → Поверх → Приміщення → Обладнання), технічний стан, дати оглядів, архівація.
- **Реєстр заявок та робіт:** 10 статусів життєвого циклу, пріоритети, відповідальні майстри, фотофіксація (до/під час/після), коментарі.
- **Термінові та публічні заявки:** Екстрена форма в додатку та публічний прийом заявок через QR-коди/токени об'єктів (`/report/[token]`).
- **Планування та графік:** Річний план, календарний розклад і канбан-дошка за статусами на спільних фільтрах URL. Запобігання циклам залежностей робіт.
- **Матеріали:** Довідник матеріалів, фіксація потреб під роботу, списання використання, аудовані коригування залишків.
- **Бюджет та фінанси:** Річні бюджети, погоджені асигнування під роботи, фіксація мультивалютних витрат за ручним курсом UAH, механізм сторно та попередження про перевищення лімітів.
- **Головна панель та Звіти:** Dashboard із ключовими KPI та 6 аналітичних звітів із безпечним експортом у CSV.
- **Мобільність та PWA:** Адаптивний інтерфейс для смартфонів, Web App Manifest та автономний офлайн-екран.

## Швидкий старт (локальна розробка)

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Налаштування змінних середовища
Скопіюйте `.env.example` у `.env.local` та вкажіть параметри підключення до Supabase:
```bash
cp .env.example .env.local
```

### 3. Запуск тестів та перевірки типів
```bash
npm run typecheck
npm test
```

### 4. Запуск локального сервера
```bash
npm run dev
```
Додаток буде доступний за адресою [http://localhost:3000](http://localhost:3000).
